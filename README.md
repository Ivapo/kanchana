# Kanchana

> **Kanchana** (Quechua: *lamp*). An iPad PWA that turns the screen into a
> decorative or utility lamp — solid-color surface, color-temperature dial,
> dimmer, presets, keep-screen-on. No app store. No network. No telemetry.

**Live**: [ivapo.github.io/kanchana](https://ivapo.github.io/kanchana/) ·
deployed automatically from `main` via `.github/workflows/deploy.yml`.

This repo is also a deliberately small experiment in **how many tokens it
takes to produce a verifiable app**. See [`TOKENS.md`](./TOKENS.md).

---

## What it does (v1)

1. **Fullscreen solid-color surface** filling the whole viewport, edge to edge.
2. **Warmth control** in Kelvin from candle (~1800 K) to cool daylight (~6500 K),
   mapped to RGB via the Tanner-Helland black-body fit.
3. **Brightness control** — dims by compositing toward black (see *Constraints*).
4. **Presets**: Candle, Warm, Daylight, Cool.
5. **Screen Wake Lock** to keep the iPad awake while the lamp is on; re-acquires
   on `visibilitychange`. Degrades gracefully on browsers without the API.
6. **Installable PWA**: web manifest, service worker, offline-capable.
7. **Controls auto-hide** after ~3.5 s of inactivity; tap the surface to bring
   them back.

## How to run (dev)

You need [Bun](https://bun.sh) ≥ 1.1.

```sh
bun run dev          # serves on http://localhost:5173
bun test             # 19 pure-logic + manifest-integrity tests
bun run icons        # regenerate PNG icons from the radial-gradient recipe
```

The dev server is intentionally tiny (`server.js`, ~60 lines) so the
production path matches dev: same routes, same MIME types, real `sw.js`
served same-origin. To reach the app from an iPad on the same Wi-Fi, find
your Mac's LAN IP (`ipconfig getifaddr en0`) and open
`http://<ip>:5173` in iPad Safari.

## How to install on iPad

Service workers require **HTTPS or `localhost`**. Plain LAN IP over HTTP
will *render* the app but won't allow it to install as a PWA. Two ways to
get HTTPS for local install:

- Easiest: tunnel with `bunx serve --ssl-cert` / `caddy` / `mkcert`-backed
  reverse proxy, or use `cloudflared tunnel`.
- Or deploy the static files anywhere (GitHub Pages, Cloudflare Pages,
  Netlify — all four files in `/`, plus `src/`, `styles/`, `icons/`).

Then on the iPad:

1. Open the URL in **Safari** (not Chrome — only Safari can install PWAs
   on iOS/iPadOS).
2. Tap the **Share** button → **Add to Home Screen**.
3. Confirm. The Kanchana icon appears on the home screen.
4. Launch from the home screen — the app opens in standalone mode (no
   Safari chrome).

## Constraints (real, not bugs)

- **iOS does not let web pages change hardware brightness.** The dimmer
  scales the rendered RGB toward black. The backlight is unchanged, so a
  "10 %" Kanchana still consumes roughly the same backlight power as a
  full-white screen. If you want a darker *and* cooler-running lamp, also
  drop the iPad's system brightness in Control Center.
- **Color is approximate.** The Kelvin→RGB fit (Tanner Helland) is the
  same one most ambient-lighting projects use. It is good enough to look
  right; it is not calibrated against an SPD.
- **Wake Lock release on hide is by design.** When you switch apps the
  platform releases the lock. We re-acquire it on `visibilitychange`, so
  a glance at notifications is transparent — but a long detour to another
  app means the iPad may sleep before you come back.
- **SVG-only manifest icons fall back to PNG.** iOS prefers PNG for the
  apple-touch icon; we ship both 192/512 PNGs (generated by
  `scripts/make-icons.js`) and the SVG.
